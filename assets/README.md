# Assets

- `mastodon-avatar.png` / `mastodon-avatar.svg` — avatar for the bot's Mastodon account (see [#3](https://github.com/schmidt-software/song-quote-bot/issues/3)). Upload the PNG under *Settings → Profile → Avatar* on the account used for `MASTODON_ACCESS_TOKEN`.
- `mastodon-banner.png` / `mastodon-banner.svg` — profile header/banner (1500x500) for the same account. Upload the PNG under *Settings → Profile → Header*. Keep important content out of the bottom-left corner - the avatar overlaps it on the profile page.
